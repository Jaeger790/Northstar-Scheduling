# Portfolio screenshot checklist

Once the app is running, use only fictional data (for example, Acme Studio and Northwind Labs), then capture:

1. Overview/dashboard showing metric cards and upcoming appointments.
2. Appointment planner showing search/filter and the editor panel.
3. Customer directory with a sample record selected.
4. Reports showing counts across types and contact workload.

Save PNGs under `docs/screenshots/`, and reference them in the README. Never publish real customer information or credentials.
