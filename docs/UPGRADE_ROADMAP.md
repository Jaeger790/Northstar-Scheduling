# Recommended feature roadmap

**Phase 1: quality and operations** — full UI testing; improved password reset/rotation; CSV export; backup/restore and data integrity workflow; multi-resolution UI checks; documented keyboard shortcuts.

**Phase 2: scheduling features** — calendar grid, office hours per contact, time-off, recurring appointments, reschedule by drag-and-drop, reminders, event statuses, conflict visualization.

**Phase 3: product-grade engineering** — role-based access, migration/version management, dedicated authentication provider, data retention/privacy, encryption at rest, richer audit trails, installer packaging and automatic update checks.

**Phase 4: integrations** — optional external calendar sync with OAuth and opt-in notifications, multi-user server synchronization, abstract database backend and migration tool for legacy MySQL exports.
